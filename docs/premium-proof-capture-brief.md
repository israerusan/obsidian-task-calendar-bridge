# Task Calendar Bridge premium proof capture brief

Goal: create one honest premium-proof asset that answers "why pay?" in a few seconds.

## Primary story

Free proves export works.
Pro makes the calendar stay alive.

The asset should show that this is not just an `.ics` exporter. It is a live bridge between Markdown tasks in Obsidian and a real calendar workflow.

## Best asset to create next

Type: short GIF, 5–6 seconds

Story arc:
1. start on a dated task in Obsidian that already contains a Pro-only workflow signal
2. trigger export or let auto-export run
3. show the resulting calendar view with the update visible
4. end on the calendar proving the workflow is now subscription-friendly / recurring / reminder-aware

## Recommended demo note content

Use realistic tasks with obvious calendar consequences:

- [ ] Weekly founder sync [due:: 2026-08-05] [start:: 09:30] [duration:: 45m] 🔁 every week on Wednesday #team
- [ ] Customer onboarding call [due:: 2026-08-05] [start:: 14:00] [duration:: 1h] [reminder:: 10m] #sales
- [ ] Publish launch calendar [due:: 2026-08-06] #launch

Why these work:
- recurrence is instantly legible
- reminder text is easy to highlight in the calendar proof
- tags make the exported output look real rather than synthetic

## Capture variants

### Variant A — strongest GIF

Headline to support it:
Write the task once. Let your calendar keep up.

Sequence:
1. Obsidian note visible with recurring task and reminder task
2. small interaction: edit one task date/time or add the reminder field
3. export runs, or auto-export indicator appears
4. cut to exported calendar proof showing:
   - recurring event text
   - reminder/alarm text
   - same event on the updated date/time

What must be legible:
- repeating event signal
- reminder signal
- that the output came from the edited task

### Variant B — static premium still

Headline to support it:
From Markdown tasks to a calendar you can subscribe to.

Composition:
- left: clean crop of the real Obsidian note
- right: exported calendar view from the real generated `.ics`
- include visible chips or callouts for:
  - Repeats weekly
  - Alarm: 10 min before
  - Full vault export
  - Auto-export ready

Use this if the GIF ends up too busy.

## What the asset must prove

It should prove at least 2 of these at a glance:
- recurring events are real
- reminders survive export
- Pro is for full-vault / live workflow use, not just one-off export
- subscription workflow is the real destination, not repeated imports

## What not to do

- do not make the asset a generic full-window Obsidian screenshot
- do not bury the premium signal in tiny side text
- do not lead with raw settings screens
- do not make the GIF depend on reading a paragraph to understand it
- do not fake a calendar UI that did not come from the real `.ics`
